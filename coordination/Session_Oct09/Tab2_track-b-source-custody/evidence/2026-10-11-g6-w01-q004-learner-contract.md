## Minimum mathematical lesson contract (new agent analysis, NOT the publisher item)
**Assumptions:** input column is x and output column is y, observed pairs have at least two distinct x-values; target model is affine `y=mx+b` (or equivalent `ax+by+c=0`, allowing appropriate non-degenerate coefficients). Without an explicit linear-model assumption, finitely many pairs do **not** uniquely determine a general function. If the two x-values are equal while y differs, no single-valued y(x) fits.
**Inferential jump:** *rather than guess a formula from superficial numbers*, recognize that a linear model has a constant change in y per unit change in x; compute `m=(y2-y1)/(x2-x1)` from two distinct x-values, compute `b=y1-m*x1`, then independently test every observed pair against both sides; distinguish slope, intercept, x/y orientation and equivalent equation forms.
**Why each step is valid:** subtracting `y_i=m x_i+b` for two observed pairs removes the same intercept b and gives `Δy=mΔx`; dividing requires `Δx≠0`. Back-substitution determines b. Each additional input/output pair supplies a separate falsification of the single linear rule; **agreement is within the assumed affine model**, not proof no non-linear alternative exists.
**Copyright-free synthetic example solely to specify teaching/acceptance:** pairs `(0,2),(2,8),(4,14)` have `Δy/Δx=6/2=3`, and `b=2`; candidate `y=3x+2` checks each row. Independent transfer asks for `y` at `x=5` (**17**), and/or derives a different candidate from fresh pairs; do NOT substitute these rows for Q004 or declare Q004 official solution from this example. Existing prior Q004 agent computation `y=2x−1` is *historical source-research claim only*.
**Representation bridge:** physically label table columns `x,y`, ordered pairs `(x,y)`, `Δx,Δy`, symbol `m`, intercept `b`, and a line through plotted pairs. Force two-way table↔symbol checks, and interpret `b` as y at x=0 (not merely the first listed y if first x≠0).
**Misconceptions and repairs:** `y/x` instead of `Δy/Δx` falsely forces b=0 — compare two non-origin pairs; swapping x/y reverses slope — map labelled table columns to coordinates; judging from one row — demand two distinct x and independent third-row check; accepting a formula from two data points without checking remaining rows — calculate residual per row; treating observed points as proof of unique arbitrary formula — state linear model constraint.
