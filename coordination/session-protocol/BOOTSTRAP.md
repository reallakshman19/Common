If you have no descriptor, propose one from the template using observed identities
and the existing assignment authority. Unknown fields stay unknown; do not
self-certify activation, qualification, automated transport or acceptance.

The Owner/coordinator's existing authorization governs adoption. CASP does not impose another universal approval round. A human may manually supply a registered request to an agent without claiming automated delivery. Keep the observed paste/ACK facts separate from any unverified adapter capability.
