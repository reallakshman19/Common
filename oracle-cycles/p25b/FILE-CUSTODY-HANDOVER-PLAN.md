`IDENTIFIED → SOURCE_BYTES_OBSERVED → PRIVATE_UPLOADED → RECIPIENT_DOWNLOADED → BYTE_MATCHED → SCOPE_REVIEWED → OWNER_ACCEPTED`.
At each transition record **who observed what, when, under what access, with exact byte identity**.
