This is a difficult engineering identity problem, not a generic fixed-column replace. A logical NODE number exists within one CII. A physical ELEMENT is a particular 15-row occurrence with FROM/TO endpoints and engineering real fields. ELEMENTS auxiliary pointers reference typed associated sections. The same source/target numeric field, node pair or pointer integer is **not** proof of corresponding engineering identity or effective meaning.
