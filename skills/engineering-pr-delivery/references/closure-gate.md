# Closure Gate

Before ready-for-review/closure, verify:

- live PR/base/head state reconciled;
- report current under the `REPORT_BASIS_HEAD` rule;
- mission/scope/acceptance dispositioned;
- implementation/integration states explicit;
- active findings dispositioned;
- changed-file ledger matches actual PR files;
- no unexplained files;
- current review/check state recorded;
- software validation dispositioned;
- engineering validation dispositioned where required;
- NOT_RUN items explicit;
- authority/invariants current;
- multi-agent overlaps/claims reconciled;
- exact next action current;
- handover readiness is `READY`.

While technical implementation remains, Appendix A must be `CURRENT`.

Appendix A may be `NOT_REQUIRED` only when no further technical implementation authority is needed and only owner/review/merge actions remain.

Do not merge unless explicitly authorized.
