# Standalone Two-Pass Prompt Generator

Use this package for the current V3.1 two-pass handover/reasoning flow:

```text
PASS 1 — INDEPENDENT SYSTEM BASELINE
repository/application reality without issue/task/action bias

PASS 2 — IMPROVE, RECONCILE, PLAN
high-ROI improvement proposals + actual task reconciliation + Owner-approved durable plan
```

Pass 2 contains the human approval boundary; approval continuation is not a third pass.
