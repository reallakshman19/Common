# Golden reference — distinguish numerical agreement from intended-use validity

Derive the axial reference under its stated assumptions. Convert E to 210000
N/mm² and F to 25000 N. `u=FL/(EA)=25/56 mm≈0.446428571 mm`; uniform axial stress
is 62.5 N/mm² (MPa). This is an analytic reference, not a fresh solver run. Report
screenshot values as supplied approximate agreement; no invented tolerance permits
a qualification verdict.

Two solvers may share the same axial idealization or inputs. Agreement does not
establish valid bucket root/weld/contact stresses. Identify intended-use gaps
separately: actual geometry, load paths, restraints/contact, material behavior and
applicable acceptance basis. Missing bucket facts block bucket assessment, not
this useful axial derivation/applicability note.

Retain the reference for its legitimate verification purpose. Reserve engineering
acceptance and the bucket idealization for actual authority/qualification. Do not
invent boundary conditions, mesh density or an acceptance code to fill the report.
Do not interpret convergence or dimensionally consistent arithmetic as physical
model validation. A changed physical idealization requires new applicability
reasoning, not automatic transfer of this reference's result.
