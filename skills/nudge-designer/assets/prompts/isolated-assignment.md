do not ask the worker to reconstruct project history or choose a planning system.

{{Known tools/runtime conditions, or UNKNOWN and the useful fallback}}

Optional pointer for an unreliable channel:

```text
[{{sender}} · {{canonical assignment id}}] {{one-line purpose}}.
Read the issued brief at {{accessible durable locator}}, revision {{revision}}.
Verify its file bytes against {{full SHA-256 or full-hash manifest locator}}.
Reply through {{channel}} using {{documented correlation rule}}.
```

A displayed hash prefix is a convenience, not full content verification. Preserve
the exact issued packet; the pointer neither dispatches it nor expands authority.
