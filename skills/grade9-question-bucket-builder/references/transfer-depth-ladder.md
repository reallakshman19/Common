# Transfer Depth Ladder

## Purpose

Transfer questions must change reasoning, not merely numbers.

## Levels

### Level A - Near transfer

Same invariant, changed numbers or representation.

Example: same relative-speed boat problem with a different distance and time.

### Level B - Structural transfer

The invariant is present but not named by the wording. The student must recognize which bucket applies.

Example: a movement story where total is conserved but the words do not say `redistribution`.

### Level C - Generalisation

Introduce parameters, prove a pattern, derive a condition, classify possibilities, or work backwards.

Example: for a transfer fraction `1/k`, derive when a whole-number solution exists.

### Level D - Olympiad-foundation

Requires an additional structural insight beyond routine execution.

Example: replacing visible fractions with a substitution/invariant, or proving a parity/divisibility condition.

## Rule

An IOQM-style or IMO-foundation item must not be only the source question with harder numbers.

## Labelling

Use explicit labels:

- `CBSE/NCERT-aligned adapted`
- `IOQM-style adapted`
- `IOQM verified bridge`
- `IMO-foundation author-created`
- `Author-created transfer`

Never label an adapted item as official.

## Minimum transfer set for a PDF bucket

Unless the user asks for a shorter artifact, include:

1. one near transfer;
2. one structural transfer;
3. one generalisation or olympiad-foundation transfer.

## Transfer quality check

Before finalising, ask:

```text
Does this transfer item require a new recognition decision or deeper invariant use?
```

If the answer is no, downgrade it to near transfer and add a stronger item.
