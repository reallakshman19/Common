## Label discipline

Use only these labels:

- `SOURCE` — direct source question.
- `SOURCE-ADAPTED` — minor wording/layout cleanup from source.
- `CBSE/NCERT-ALIGNED` — syllabus-style generated item, not a past-paper claim.
- `IOQM-VERIFIED` — exact official IOQM item, with year and question number verified.
- `IOQM-STYLE ADAPTED` — competition-style generated item.
- `IMO-FOUNDATION TRANSFER` — olympiad-foundation generated extension.

Do not label generated questions as official past-paper questions.
