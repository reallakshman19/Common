# Pedagogy Progression

## Purpose

A bucket is not a pile of similar questions. It is a controlled progression from recognition to transfer.

## Required learner route

```text
SEE -> REALIZE -> UNDERSTAND -> ADOPT
```

Operational solving route:

```text
RECOGNIZE -> SOLVE -> CHECK -> TRANSFER
```

## Faded support ladder

Use this default progression unless the user asks for a different form.

```text
Level 0  Pattern Crack
Level 1  Fully worked anchor
Level 2  Worked source extension
Level 3  Partly worked adapted item
Level 4  Independent same-structure item
Level 5  Structural transfer
Level 6  Olympiad-foundation/generalisation
```

### Level 0 - Pattern Crack

Student should see:

- surface wording;
- hidden invariant;
- first useful line;
- common wrong start.

### Level 1 - Fully worked anchor

Use one source question as the seed.

Required blocks:

- Concept;
- Application;
- Solution;
- Check taxonomy;
- First-move sentence.

### Level 2 - Worked source extension

Use source questions from the same bucket. Show what changed and what stayed invariant.

### Level 3 - Partly worked adapted item

Give the setup and first move, then leave one or two steps for the student before showing compact answer.

### Level 4 - Independent same-structure item

No full scaffold. Include answer key at the end.

### Level 5 - Structural transfer

The student must recognize the invariant in a changed representation.

### Level 6 - Olympiad-foundation/generalisation

Add a parameter, proof, classification, reverse construction, invariant argument, or extra structural insight.

## First-move contract

Every bucket must answer:

```text
If a student sees a new problem of this family, what should they write in the first 10-20 seconds?
```

Examples:

- Fraction equation: `LCM = ...`
- Redistribution: `Let first group initially be x; second group is total - x.`
- Hidden coordinate variables: solve the visible coordinates first.
- Equilateral third vertex: `Let P(x,y); write PA^2 = AB^2 and PB^2 = AB^2.`

## Tone rule

Use student-facing workbook language. Keep source-custody or diagnostic comments compact and supportive.
