# R1-C — actual merged-module source→research→Owner-intent integration

Governed by [parent #787](https://github.com/reallaksh19/Common/issues/787), [R1-C #806](https://github.com/reallaksh19/Common/issues/806). This integration **imports the three real merged modules on main**, not copied fixtures or prior legacy v3.5 engines: `validate/traceClaim/canonicalJSON`, `readNativeOwnerComment`, and `evaluateDeclaredScope`.

`inspectResearchDecision()` validates the supplied structural provenance graph, joins an OwnerDecision to the selected acceptance claim/original Owner intent and exact research-finding IDs, fetches the decision's native GitHub comment by repo/issue/id and pinned SHA256, **replaces the caller's alleged source receipt** with the source reader output, then checks declared policy scope. Return includes Owner raw_text and separate original chat UNKNOWN / first durable mirror fields, typed source and a deterministic digest of this *read-only diagnostic view*.

**Hard safety limit:** both graph and declared grant are supplied by an agent and hence untrusted. Even a real GitHub OWNER comment and matching declared scope are not an adopted Owner research decision, original chat provenance, independently accepted evidence, or authorization. Result always `authorization_granted:false`, `independently_accepted:false`, `live_writer_enabled:false`. `INJECTED_UNVERIFIED` test transport never masquerades as native source observation. Native source mismatch = REFUTED, fetch failure = UNKNOWN. Code has no GitHub write capability or tokens.

Tests run offline using a synthetic GitHub transport; they **do not establish a live GitHub production source-read success**. An external, separate native GitHub API readback of comment [Common #789 / 6062832157](https://github.com/reallaksh19/Common/issues/789#issuecomment-6062832157) only proves its issuer and permalink. That comment's text is NOT adopted research content. No issuer/grant validity proof is provided here; next R1-B.2b must verify a preexisting independently authorized and versioned Owner grant before any live operation.
