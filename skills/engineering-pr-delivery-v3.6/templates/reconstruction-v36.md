# Source-based continuation note — optional structure

Use only for a cold takeover without a selected BuddyRunner, two-pass or three-pass
flow. For a completed one, reuse its outputs and do not fill this as an extra step.
Use the existing native record; this template is not an exam or acceptance schema.

Describe the Owner's outcome and amendments in your own words. Connect the next
task to the whole outcome and cite the actual original sources.

Record the exact candidate/input basis and available authority. Trace a concrete
input/action through the actual producers and consumers to its observable result.
Explain necessary identities, units, state or model assumptions rather than
listing file names alone.

Distinguish established facts, reported claims, hypotheses and unknowns. Give
decisive source/witness references, a contrary check and its remaining limits.
Retain valid prior work, drift, unresolved items and justified improvements.

State the next bounded authorized action, success/failure evidence and remaining
integration work. Record relevant execution access early; for a restriction,
give attempt, observation, affected scope and next feasible route. Request only
a genuinely unresolved Owner decision, with concrete options when useful.
