# Golden example — clean five-prompt packet

Publish the five prompts as the reasoning artifact. Keep generator diagnostics out of the agent-facing issue comment.

```text
SCHEMA
TPG-3P-<current>

TARGET
<child issue / bounded responsibility>

BASIS
<programme + exact observed source basis>

PROMPT 0.5 — IMAGINE FROM PROGRAMME
<programme-contribution reasoning>

PROMPT 1 — IMAGINE
<independent situated problem reasoning>

PROMPT 2 — UNDERSTAND
<verified live reality>

PROMPT 2.5 — RECONCILE REALITY AND DIRECTION
<direction contract>

PROMPT 3 — REVALIDATE AND MOVE FORWARD
<live refresh + agent-authored IMPLEMENTATION_PLAN handoff>
```

Do not publish dozens of internal `GATE: PASS` diagnostics as if they were engineering instructions.
