# Verification and limits

This independent package is scoped to task design, with one neutral map schema,
an offline validator/renderer/frontier/impact tool and synthetic worked references.
It imports no other skill and changes no existing consumer or delivery protocol.

The focused suite exercises actual schema/reference/graph/coverage checks, scoped
unknown propagation, preserved constraints, canonical binding, selective impact,
strict JSON, CLI execution and input/output protection. A copied-package test runs
without sibling skills or a repository. Missing `jsonschema` is an observed NOT_RUN;
it does not turn a failed tool startup into a successful structural check.

Local execution passed all 29 focused tests on Python 3.12. The Skill Creator
metadata check, Python/JSON syntax, Markdown links and source/documentation diff
whitespace checks also passed. Archived native Markdown retains generated quote
spacing and a final blank line to preserve issued byte hashes; the unrestricted
diff whitespace check reports those archive lines. Hosted Python 3.10/3.12 results belong to the delivery PR's exact head and
must be read there; a configured workflow alone is not an executed result.

The [forward application assessment](../examples/forward/ASSESSMENT.md) links two
fresh task designs, actual independent local note work, an unchanged Nudge Designer
consumer, original inputs and native results. It preserves a checker-change
mismatch and stable recheck, plus the native verbose worker output and a separate
parent-authored compact reference. Consumer fit remains NOT_ESTABLISHED.

These checks establish bounded observations, not semantic completeness, source
authenticity, low-thinking model qualification or integrated domain acceptance.
