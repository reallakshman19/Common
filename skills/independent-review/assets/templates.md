# Optional native records

Keep these in an existing issue/document when possible. Omit unused fields rather
than inventing metadata. Link an accessible detailed pack instead of repeating it.

## Review Case

```text
Case / task: <identity and revision, when available>
Purpose: <Owner's intended outcome and original source/amendment links>
Candidate: <exact artifact/repository/revision; base/integration surface if relevant>
Inputs/criteria: <authoritative accessible locations, revisions and hashes as useful>
Claims/contrast: <what is assessed; a plausible wrong result for each material claim>
Understanding: <necessary model/state knowledge and unresolved premises>
Arrangement: <available participants, responsibilities, DIRECT/GUIDED support>
Boundaries: <allowed work, protected invariants and reserved decisions>
Return: <native report location; optional task/map/tracker/assignment mappings>
```

## Review Result

```text
Run / case / actual candidate: <distinct identities>
Reviewer/contributions: <author relation and basis; earlier contributions>
Independence/exposure: <context, expectation derivation, method, execution, lineage>
Claim results: <supported / contradicted / inconclusive / not run, with witnesses>
Findings: <source/candidate locator, observed vs expected, consequence, reproduction>
Coverage: <assessed and excluded scope, unknowns and missing checks>
Verdict: <PASS / NEEDS_WORK / FAIL / INCONCLUSIVE within an explicit scope>
Next: <useful action and responsible available participant; existing authority>
```

An overall verdict does not erase per-claim results. Use FAIL for a demonstrated
failure of the assessed outcome, NEEDS_WORK for a material correction or coverage
gap under the stated criteria, and INCONCLUSIVE when available evidence cannot
settle that scope. PASS needs support for its stated scope, not universal certainty.
Keep native project verdicts alongside this summary when their vocabulary differs.

## Reconciliation

```text
Reviewed/current subjects: <exact IDs and observation source/time>
Consumer response: <accepted/disputed findings with reason; reviewer report preserved>
Reusable evidence: <what still applies and why>
Affected work: <correction/investigation and integration dependencies>
Remaining Owner outcome: <unestablished acceptance, deferred work and next action>
```
