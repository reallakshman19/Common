## GitHub comment relay and artifact-only PR
When the owning task issue and permissions exist, post the evidence summary as a [delimited handover block](COMMENT_BLOCK.md) on the **existing issue**, read it back, and give the successor its permalink. The Owner does **not** have to paste the agent's response. For a ZIP or single binary, use the public [Common project-wise handoff folder](../../../../local-agent-handoffs/README.md) if publication is safe, and make a **dedicated one-file DRAFT artifact PR** ([checklist](ARTIFACT_PR_CHECKLIST.md)), with only the ZIP as a diff path, not its sidecars or implementation changes. Record artifact PR URL/head SHA, exact file path, bytes and SHA-256 in that issue block. Confirm GitHub draft status and actual server diff. Never call transfer completion Owner acceptance, product PASS, merge or deployment.

Producer's self-check is **not** independent verification. Never convert missing sources or unexecuted tests into PASS. Preserve original reports unchanged.
