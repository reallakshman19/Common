# Oracle OnBoard — project-first four-document template

**For an Owner-selected new/promoted Oracle or a candidate successor.** This is **not a new protocol, gate, role or separate approval process**.  A project's real [Owner AIM/Project Home](../../../PROJECT_HOME_GUIDE.md), original engineering evidence, canonical native task and activated Cycle (if any) **remain the source**; these templates are prompts for content, not extra required copies or approval gates.

The four [immutable 3DC handover documents at bf02e54e](https://github.com/reallakshman19/Common/tree/bf02e54e1b453c3206ae366de7d65f41c94ab0d4/relay/AGENT_WORK/3DC-XML-CII/oracle-continuity-20261025/payload) supply a **quality benchmark**, not engineering facts for another project. Common's [complete, published self-example](https://github.com/reallakshman19/Common/tree/main/relay/AGENT_WORK/common-agent-work-oracle-continuity/knowledge-20261025) demonstrates the same causal depth for Oracle continuity itself. **For CIIFR or another project, write their own four source-grounded knowledge classes** or reference equivalent native records:

1. [CONCEPT_NOTE.md](CONCEPT_NOTE.md) — Owner WHY, amendments, real end-user journey and observed product versus promises.
2. [ARCHITECTURE_COMPLEX_LOGIC.md](ARCHITECTURE_COMPLEX_LOGIC.md) — original-source semantics, architecture/invariants, candidate and trust flow, source-code links.
3. [ARCHITECTURE_DECISIONS_AND_CHALLENGES.md](ARCHITECTURE_DECISIONS_AND_CHALLENGES.md) — consequential decisions and rejected alternatives, source-level wrong cases and falsifiers, engineering evidence distinctions.
4. [ORACLE_HANDOVER.md](ORACLE_HANDOVER.md) — true canonical state, actor/Chat-ID routing, current native issue/PR heads, file custody, unresolved claim-scoped evidence and one executable NOW.

[ORACLE_ONBOARD_PROMPT.md](ORACLE_ONBOARD_PROMPT.md) is a **copy-ready request** with explicit roles:
- **New project Oracle:** only coordinates after actual Owner/OTM native assignment and source/writer capability checks.
- **Promoted incumbent agent:** does not simultaneously continue producing and self-reviewing the same work; previous author evidence and ongoing task assignments survive.
- **Successor candidate:** **READ_ONLY** until distinct explicit Owner-authorized cutover, current epoch/CAS publication and real write isolation. A correct explanation, a title or Chat ID is not transfer authority.
- **Established Oracle:** use `Cycle now` / changed-source delta-only continuation (when activated), **not** a fresh four-file onboarding exercise.

**Issue title and traffic-light hygiene:** follow [native title/Chat-ID rules](../../references/TITLE_AND_TRAFFIC_HYGIENE.md). If manually owned, issue title `🟡 [<TASK-ID>][O:<CHAT-ID8>] <specific scope>`; if **v3.5 DELP-managed**, **never hand-edit its issue title, traffic light, percentage, task hierarchy or status**. Preserve Chat-ID8 in the actual issue/assignment metadata and let DELP publish. Owner-facing `OWNER_ACTION: NONE` by default for Oracle-solvable work, `REQUIRED` only for a real reserved decision.

**Execution-first:** Oracle recovers source, reconciles work already done, diagnoses available anomalies, routes a bounded next task, and keeps other safe work moving. One unrun reviewer/browser/input claim is **not** a blanket G2 or entire-project HOLD. Actual Writer exclusion, protected source access, exact-head review and release authority still apply to their affected operations.

**Artifact transfer:** (1) public-safe immutable Common relay, or (2) Owner-authorized Google Drive Handoffs with a sanitized Common receipt; one mandatory for any *completed cross-agent transfer*. `sandbox:` is `LOCAL_ONLY / NOT_TRANSFERRED`. The Oracle must not upgrade producer SHA to receiver proof or a self-check to an independent verdict. See [ARTIFACT_RELAY](../../../ARTIFACT_RELAY.md).

**Relationship to protocol:** this folder augments existing [Oracle Continuity](../../../oracle-continuity/PROTOCOL.md), [Standalone Handover](../../../oracle-standalone/references/ORACLE_HANDOVER_PROTOCOL.md), [Oracle OnBoard guide](../../references/ORACLE_ONBOARD.md), [Cycle](../../../../../oracle-cycles/PROTOCOL.md) and the selected OTM/standalone native authority. It creates **no new general `CURRENT.json`, status database, reviewer, merge authorization, threshold, or control epoch**.
