# Seven-element assignment template

The Designer fills this from the real request. Preserve exact conditions and direct
references; state UNKNOWN rather than leaving invented example values. Use the
existing native task format if it already carries these elements. This is not a
new approval form or a complete risk census.

```text
Purpose
{{Owner outcome; why this step contributes; relevant parent outcome}}

One bounded task
{{One coherent, checkable artifact/result; relevant understanding required}}
{{GUIDED concrete method/example or OPEN investigation question, when applicable}}

Authoritative inputs
{{Owning sources/amendments, exact files/fixtures/revisions and issued snapshots}}
{{Original conditions verbatim; distinguish supplied reports from actual observations}}
{{Artifact derivation/reference exposure where it affects the assessed claim}}

Boundaries
{{Permitted change/action; preserved behavior/conditions; reserved decisions}}
{{Actual task-specific capabilities/tools and their basis; unknowns where necessary}}
{{Allowed/withheld inputs and relevant earlier exposure for an isolated exercise}}

Success criteria
{{Observable result; meaningful negative/contrast case; evidence that changes the view}}
{{Part-level criteria, roll-up/UNKNOWN and edge cases if judging several parts}}

Uncertainty handling
{{Missing fact or restriction; exactly which action it blocks; when/what to return}}
{{Useful independent work that remains within actual authority}}

Evidence and continuation
{{Actual results/artifacts in the native reporting format, attempts and execution limits}}
{{Unresolved parent outcomes; next feasible action or proposal; issued binding if used}}
{{Material claim witnesses, coverage and selected sender checks where relevant}}
{{SELF-ASSESSED when judging own output; assignment/tracker/reply mapping if used}}
```

Read the filled brief as the recipient. Remove irrelevant boilerplate. A GUIDED
method must be actionable, not just “think carefully” or the deliverable repeated.
Do not combine diagnosis, a hidden model choice and several repairs to make one
assignment appear small. Do not remove the rationale when shortening it.
Apply the relevant [pre-send checks](brief-check.md). For a fresh task-local worker,
use [the isolated variant](isolated-assignment.md) when it reduces history dependence.
