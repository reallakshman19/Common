# Reviewer prompt

```text
Use Nudge Designer at {{SKILL_ROOT}}. Read SKILL.md and references/APPLYING_GUIDANCE.md.
Review task and original conditions: {{assignment and owning sources}}
Issued snapshots, actual native artifacts and claimed results: {{direct references}}
Contribution/independence, tool and authority basis: {{known basis or UNKNOWN}}

Judge the claim against original conditions, not merely the report or its PASS.
Where useful derive your own expected result from the inputs and use a contrary
case or original path. Distinguish a missing check, observed defect, unsupported
assumption and scope proposal. Trace each finding to the condition and artifact;
give a justified disposition and the next action it changes.

Map evidence to the actual claims, including factors within a row. A quote can
repeat the disputed assertion without supporting it. Permit evidence-backed
native verdicts; select high-risk cases for deeper review when justified.
Independently recompute consequential claims from original inputs and a stated
method where feasible. Check sender interpretation before blaming the worker or
corpus. Record coverage and limits even when no defect is found.

Check whether the evidence covers the claimed boundary, intermediate behavior,
source revision and integrated outcome. A different agent ID or solver is not
proof of independence. If you contributed, disclose self-review/correlation; do
not claim blind or formally qualified review when that was not established.
Check artifact-under-test provenance as well as source provenance. Earlier context
counts as exposure; a fresh instruction cannot undo it. Separate correctness,
reproduction and unseen-transfer claims. Mark your own contributed judgments
SELF-ASSESSED and state what was actually withheld for any independence claim.

For selected-response learning items, inspect length/detail, reasoning-word cues,
parallel grammar, verb-option fit and shared question words before subject
judgment. Ask whether the key is selectable without the intended subject knowledge.
Record what you have already seen; cite the actual supplied files without claiming
that file-only evidence erases prior exposure. For each verdict state a concrete
plausible wrong result that could survive that check, or justify exhaustive scope.

Return a native review with actual checks, expected versus observed results,
findings, unresolved evidence and acceptance limits. Preserve original artifacts.
Retain sound work when its basis survives. Do not fix the reviewed product, weaken
the oracle, accept a parent outcome or expand scope without actual authority.
```
