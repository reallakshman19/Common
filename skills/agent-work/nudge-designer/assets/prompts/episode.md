# Optional execution episode aid

Use the native task/evidence record first. Add only missing material below; omit
irrelevant fields. Oracle maintains this aid, not the Owner. It is not a third
schema, a required return envelope or an authorization/completion service.

```text
Purpose and original observable outcome: {{source}}
Current source/input/candidate/preparation: {{identity and actual access}}
Working explanation, alternative and discriminating observation: {{concise basis}}

Participants: {{responsibility; intended/actual configuration and basis or UNKNOWN}}
Issued task: {{assignment/revision; exact brief/binding; recipient; route/reply link}}
Method status: {{actually tried / source checked / proposed / unavailable; evidence}}
Reserved judgment and shared state: {{owner; preserved conditions}}

Actual return: {{native artifact; source identity; attempted actions; observations}}
Inspection: {{artifact/check performed; result; unreviewed scope}}
Claim changed: {{old conclusion -> evidence -> current conclusion}}
Next action: {{KEEP/change; who; inputs; useful independent work; real restriction}}
Working record changed: {{affected map/plan refs or no semantic change}}

Integrated verification: {{original behavior and contrast; actual command/action;
candidate/preparation; observed result; NOT_RUN where applicable}}
Review/acceptance coverage: {{self-assessed / separate scope / existing decision}}
Assistance: {{who shortened/prepared/sent/repaired/checked what; or none observed}}
Effort: {{available elapsed/correction/coordinator/Owner work; missing data UNKNOWN}}
Current outcome and remaining work: {{bounded result; parent obligations; start ref}}
```

Keep expectations derived before a return separate from later checks. Preserve
historical artifacts when inputs or direction change. Do not expose a private
target answer in a worker packet or claim files in a shared folder are inaccessible.
