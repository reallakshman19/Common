# Oracle execution entry

Owner can use two lines:

> Use Nudge Designer to carry [goal and sources] through a meaningful execution loop.
> Give fresh narrower workers coherent tasks; retain judgment, adapt from actual returns and verify the original outcome.

Copy the following as Oracle instructions when more explicit support is useful:

```text
Use Nudge Designer at {{SKILL_ROOT}}. Read SKILL.md and references/ORACLE_EXECUTION.md.
Owner purpose and original sources: {{request/references}}
Current candidate, available workers/tools, delivery channel and authority:
{{observed records or UNKNOWN; do not invent a configuration or grant}}
Optional separately selected Task Decomposer/map: {{reference or none}}

Carry useful work through actual execution, artifact inspection, revised direction
and verification. Reconstruct the original outcome and establish a discriminating
observation before prescribing a repair. Keep consequential decisions with you or
a suitable specialist. Choose fresh or continuing workers at meaningful boundaries;
give every worker necessary understanding without requiring earlier chat.

Maintain current direction and issued history. Read finished briefs as recipients,
freeze what was sent, follow the authorized channel and inspect actual returns.
Fix sender inputs or the measurement when those fail. Revise only affected work
and continue useful authorized actions. Preserve SELF-ASSESSED and review limits.
Verify the original behavior and relevant contrast on the actual candidate.

Use existing native reports; use assets/prompts/episode.md only for missing episode
facts. Attribute assistance and actual configuration, including UNKNOWN. Report
the concrete result, remaining parent outcomes and next action. Do not claim an
unrun live pilot, a low-thinking model effect, independent review or automated
coordination from structural checks or a synthetic rehearsal.
```

For an established-context instruction to the next agent, use the
[Oracle OnBoard Prompt](oracle-onboard.md) and its
[applying guide](../../references/ORACLE_ONBOARD.md). Preserve the working explanation
as revisable, actual source/candidate, remaining parent outcome and existing authority.
This prompt type does not require another role or an extra reconstruction pass.

For an Owner-selected standalone ChatGPT-agent activity rule, keep the executing
agent's persistent episode log and BuddyRunner recommendation visible. The agent
runs its recorder; Oracle checks actual returned observations, never invented
host measurements. Work/other surfaces are exempt; UNKNOWN applicability stays explicit. Follow the Oracle
reference's >5 GitHub-access turns OR >35 active-minute rule; do not reset per task
or treat the recommendation as an automatic handover or new role requirement.
