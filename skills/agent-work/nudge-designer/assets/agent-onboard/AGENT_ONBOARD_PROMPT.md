## Sending discipline

The **Oracle/OTM or direct Owner** remains responsible for filling missing project-specific concepts, picking the right task/recipient and resolving available ambiguities. The agent does **not** fill missing Owner scope by inventing it. A fresh agent receives the **one real executable instruction** as part of its existing assignment, not an additional eligibility process.

**If this is an independent falsification task**, provide the original requirements and the exact candidate, with neutral wrong-case prompts; do **not** give away a private expected answer or expose the author solution unless the review is expressly non-blind. Disclose all relevant author/expectation exposure in the actual verdict.

**Golden quality benchmark:** The four immutable [3DC Oracle documents](https://github.com/reallakshman19/Common/tree/bf02e54e1b453c3206ae366de7d65f41c94ab0d4/relay/AGENT_WORK/3DC-XML-CII/oracle-continuity-20261025/payload) demonstrate causal-source depth; their CII facts or role authority are **not imported**. The four linked files in this template are scaffold text until grounded for the actual assigned project.
