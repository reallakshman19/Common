# Reference distinctions

The inventory table has a useful fresh-worker boundary: fixed inputs, one artifact
and a source-checkable oracle, retaining unknown keys rather than inventing them.
Supply purpose, exact rows/revision, interpretation, allowed output and return rule.
The worker need not load the entire project conversation or process library.

The four UI edits are speculative and coupled by one unresolved mechanism/state
contract. Retain a coherent investigation; recover a genuine action point and
usable measurement procedure with someone who has access before prescribing a
remedy. The source-analysis worker can preserve known handlers and evidence limits.
One missing browser does not block independent inventory work.

Oracle retains the integrated journey, interpretation and allocation decisions.
Freshness is task-local context management, not blind review or capability proof.
Do not withhold source identity, preparation or constraints needed for correctness.
Do not invent a generic microtask count, force an interaction or erase existing IDs.
