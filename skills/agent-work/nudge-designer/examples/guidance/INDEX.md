# Applying guidance — golden references

G01–G13 are synthetic teaching references; G14 preserves public NLM report claims
and their limits. Supplied logs/receipts are case data; no new browser, solver,
learner or product execution is claimed. “Golden”
specifies acceptable distinctions under the declared inputs, not unique wording,
complete risk coverage or production acceptance. Justified alternatives can satisfy
the same conditions. Use existing schema examples when authoring machine objects.

Trap IDs are defined in [Applying guidance](../../references/APPLYING_GUIDANCE.md).
Give a fresh agent only a raw case, the needed role prompt/guide and tools/scope.
Withhold this index's golden files and any expected diagnosis. After the task,
inspect its artifact for preserved conditions, useful evidence, unsupported claims,
correct scope and remaining outcomes. Do not score semantic quality by keyword
presence, matching the sample's prose or claiming a fixed pass count.

Try a changed condition and check the consequences: corrected geometry rather
than DOM activation, a different event order, a new stipulated gravity, a different
physical idealization, a new source revision, an unavailable tool or a changed
authority boundary. A copied old answer that no longer fits must fail review.

The [existing actual role cycle](../adapter-cycle/ASSESSMENT.md) supplies executed
local evidence and immutable history. These new cases complement that record;
they do not relabel it or replace native reporting with another governance format.
