# Reference distinctions — withhold during fresh discovery

SYN-UNIT may correctly test retrieval with unit options. A blanket numerical/unit
ban would damage the intended task. A cue-free report alone still does not
establish the key's physical truth or learner performance.

SYN-CAUSE has a plausible causal key but also uniquely shared rough/surface words
and a longer key. Script flags motivate inspection, not automatic deletion of
causal vocabulary. Repair the cue while retaining the original physical conditions;
then rerun the actual final draft's checks. The distractors' plausibility also needs
judgment; matching grammar alone cannot establish an effective item.

SYN-ARGUMENT has no causal/argument options even if its selected answer describes
a possible true observation. It does not supply a claim-to-principle justification.
A word-count/shared-word screen may return no flags and still miss this demand
failure. The reviewer must inspect the verb-option relation and subject conditions.

A useful generator return includes measured counts, flag dispositions, actual
revisions and remaining limits. A useful judge cites candidate/source relations,
declares previous exposure and separates cue, demand and subject verdicts. A
non-fresh judge remains exposed even when it cites only the files. For each verdict,
name the check's concrete surviving wrong result and a discriminating contrast,
without manufacturing a defect or claiming learner transfer from agreement.

These are synthetic reference cases, not G6–G8 reproductions or live pilot results.

The separate [fresh application receipt](forward/RECEIPT.md) preserves actual
generation, script screening and a fresh review, including exposure and inference
limits. Keep its completed outputs withheld during another discovery test.
