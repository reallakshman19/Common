# Reference distinctions

The five-row inventory has a useful fresh-context boundary: one durable output,
specified interpretation and a source-checkable oracle. Give the worker necessary
purpose/source/decision context, not the entire chat and not an empty command.

Keep the unresolved interaction diagnosis coherent. Missing browser/point evidence
limits that observation, not independent inventory work. Do not decompose the
proposed repair into ungrounded listener/hit-target/inspector microtasks or silently
choose a cause. Oracle reserves integration and consequential design judgment.

Specify what must travel across a later valid cut: pinned source/preparation,
established method, state contract, outcome/contrast and invalidation conditions.
A fresh dependent worker can read a pinned prior artifact without reading prior
conversation. More tasks or sessions is not deeper reasoning.

The copied regression supports reproduction under those conditions; it does not
alone establish unseen transfer. Record artifact/reference provenance. A fresh
session does not undo a worker's earlier reference exposure, authenticate isolation
or establish capability. Preserve self-assessment/independence limits.
