# Short entry prompts

Owner — long work:

> Use Task Decomposer for [goal and sources]. Map the whole outcome, retain useful
> prior work and detail the next useful tasks; keep later unknown work visible.

Owner — individual difficult problem:

> Use Task Decomposer for [problem and original inputs]. Keep it coherent, expose
> the understanding and unresolved judgments, and design work suitable for a
> narrower agent without assuming that agent is qualified for every decision.

Planner:

> Use the task-decomposer skill at [location]. Follow actual project rules, read
> original sources and produce a source-grounded task map and selected designs.
> Explain KEEP/SPLIT/MERGE/DISCOVER_FIRST/DEFER with evidence. Scope unknowns and
> preserve the integrated outcome. State actual checks, restrictions and next work.

Optional downstream request:

> Use Nudge Designer with this issued task design and original source references.
> Preserve its conditions and binding, choose support for the actual participant,
> and return any consequential task refinement visibly. Give the worker a concise
> operational brief with links to full context; retain the consequential unknowns.
> Keep existing authority.

These prompts request substantive outputs; they do not invoke tools, elevate
reasoning settings, dispatch participants or change governance by themselves.

Owner — fresh task-local workers:

> Use Task Decomposer for [goal/sources]. Select coherent work that a fresh worker
> can perform from a self-contained brief; minimize dependence on prior chat while
> preserving necessary understanding. Keep coupled decisions and integration with
> Oracle, and prepare selected designs for Nudge Designer if useful.

Oracle — continue through execution:

> Use Task Decomposer for [goal/sources] and carry the selected work through actual
> returns and integrated verification. Establish a usable observation/method, give
> fresh workers coherent tasks, inspect their artifacts and adapt direction from
> evidence. Retain consequential judgment and remaining parent outcomes. Attribute
> assistance and actual host configuration; maintain the records for me. Use Nudge
> Designer only if separately selected and preserve the original task meaning.

For an Owner-selected standalone ChatGPT-agent activity rule, keep the executing
agent's persistent episode log and BuddyRunner recommendation visible. The agent
runs its recorder; Oracle checks actual returned observations, never invented
host measurements. Work/other surfaces are exempt; UNKNOWN applicability stays explicit. Follow the Oracle
reference's >5 GitHub-access turns OR >35 active-minute rule; do not reset per task
or treat the recommendation as an automatic handover or new role requirement.
