# Oracle Chat Routing — standalone

Use [STANDALONE.md](STANDALONE.md) when one Owner relays work between several
agent conversations and needs a clearly labeled **routing board** and one
copy-ready next action. It is suitable for the Oracle chat itself or for any
single agent asked to coordinate manual transfers.

**No installation, scripts, schema, server, bot, cross-chat access or
Progress-page integration is needed.** This is a documentation-only,
human-mediated routing convention. It does not dispatch instructions, inspect
another chat, verify another agent's identity or authorize a release.

## Start in one message

> Use Oracle Chat Routing in standalone mode for this task. Show the Oracle /
> Coder / Reviewer conversation display IDs beside each role; treat URL suffixes
> as Owner-supplied labels, not verified identities. Show where one exact file or
> message should go now, what evidence is needed from that recipient and what
> remains reported rather than verified. Do not ask me to resend an artifact
> already reported attached, or show a fake automatic-send button.

Only ask for the receiving chat's ID when a real handoff cannot be directed
without it. Keep the complete private chat URLs and private engineering files
out of public GitHub records.

## Quick Oracle self-check

A useful answer lets the Owner see:

1. **WHERE:** role and exact known/UNKNOWN destination display ID.
2. **WHAT:** exact artifact/version and copyable job instruction (or no further send).
3. **STATE:** reported attachment versus confirmed receipt versus verified bytes.
4. **RETURN:** the specific response, test result or artifact needed next.
5. **BOUNDARY:** one stop condition, unresolved review/acceptance and privacy limits.

Prefer a short board over forms or ceremony. Repeat the board after a meaningful
handoff or change in the actual task state, not after every message.

The [Oracle Continuity Protocol](../oracle-continuity/PROTOCOL.md) remains an
optional separate structured-state contract; its schemas are not required for
this standalone mode.
