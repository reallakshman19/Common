# NWv7 example — actual planned assignment, not executed repairs

The user has two discovery returns per audit. Do not repeat them or assign a report-only round. Original brief and all authorized earlier evidence must be available in the assigned Drive task folder. Verify actual candidate HEAD and do not assume earlier patches merged. This example describes the proposed turn allocation, not actual agent activation or completed fixes.

| Task | Agent A | Agent B |
| --- | --- | --- |
| A08 Insight | ALT-A08: authority/identity, Tier-C and other feasible repairs | Original A08: take C1, correct remaining novelty, coverage, recovery, temporal and any surviving defects; cumulative tests |
| A09 Planner | Original A09: prioritize destructive dismissal/overwrite, occurrence identity, rolling lifecycle and all feasible fixes | ALT-A09: take C1, challenge durable state and any remaining occurrence/date/cache defects; fix forward |

For each task, the initial assignment explicitly grants both write turns. All native handoff and final delivery through one assigned Google Drive subfolder. A cannot leave known safety defects deliberately for B. B inherits every unresolved in-scope issue, not just named specialty. Shared-file contracts across the two different tasks must be coordinated at initial assignment or integrated on isolated branches; no overlapping writes to a common candidate. Each task ends with a cumulative candidate and native test evidence. No additional role or repeated technical-message relay.

A08 done-list: independent publisher/authority identity, deterministic retained winner, separate real events, truthful novelty/coverage and recovery, actual integrated quality output. A09 done-list: independent occurrence identity, correct revision/date/location/expiry, suggestion dismissal cannot delete saved plans, stale refresh cannot overwrite newer user intent, correct stored and reopened record. Both: source-derived positive/negative controls and reproducible native files. A missing optional historical report does not stop code correction; inability to run a required product check limits the final verdict.
