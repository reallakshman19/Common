# Describe the independence actually established

Record dimensions separately; do not calculate a score or infer one from a model
name, new chat, different wording or number of agreeing agents.

| Dimension | Record |
|---|---|
| Authorship/principal | Whether this participant contributed to the candidate; the basis for SAME, DISTINCT or UNKNOWN identity claims. |
| Context/exposure | Inherited conversation, prior author conclusions, target answers and accessed references. |
| Expected behavior | How the expectation was derived; independence from candidate assertions and known shared premises. |
| Method | Alternative calculation/observation, replayed method, inspected receipt or no execution. |
| Execution | Exact candidate/input/environment checked and actual run evidence versus reported-only evidence. |
| Upstream lineage | Whether blueprint, data, reference or expected answer came from the same producer/source assumption. |

Do not treat legitimate shared authoritative requirements as automatically invalid.
The question is which claimed independence matters to this review. A distinct
reviewer can rerun author tests usefully without establishing an independent oracle.
A same-principal fresh attempt remains self-review. A reviewer who repairs a
candidate must disclose contribution to the changed scope.

Earlier conversation, inspected files and shared memory count as exposure.
"Do this before reading that" cannot undo prior access. For reference-withheld
generation or transfer, name the withheld reference, issued input set, known prior
access and actual host isolation. Fresh context is not proof of inaccessible
workspace contents or absent training exposure. Use UNKNOWN where not established.

When useful, derive risks/expectations before reading the author's conclusions,
then reconcile against all necessary evidence. Do not hide requirements, unsafe
conditions or essential model knowledge to create artificial blindness. This is
an optional method, not a compulsory three-pass protocol.

When validating a generator or blueprint, classify artifact provenance before
using matches to establish transfer: COPIED, ADAPTED, INDEPENDENT or UNKNOWN under
the stated criterion. Trace upstream derivation too. A new producer cannot remove
reference influence already embedded in its blueprint. A producer's judgment of
its own artifact is SELF-ASSESSED. Keep correctness evidence while limiting the
unsupported generalization or independent-acceptance claim.

An unavailable separate reviewer changes what may be claimed, not whether useful
review can proceed. Return self-review/exposure limits and continue feasible work.
Only the existing project can require distinct review for a consequential decision;
this skill creates no new role quota or approval gate. Offline tools can flag a
declaration contradicting itself; they cannot authenticate a distinct principal.
