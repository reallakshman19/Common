## Important composition decisions

**Standalone means absence of OTM**, not absence of every other selected
discipline. Selected engineering delivery modes and their native
source/task issue, custody, self-check, approval and safety rules still
apply. Do not create a second issue as a competing source of the work
order. If a separate Cycle receipt inbox is activated, it serves as
a cross-role **index/transport** pointing back to native issue
evidence; it is not a replacement issue or acceptance authority.

**Changeover** has two layers: (a) Owner-facing recommendation and
routing, which the skill can describe; (b) actual session/assignment
or Oracle epoch cutover, which needs an authorized publisher and real
write-scope isolation. No “new chat = new authority” assumption.

**Oracle role separation** is contextual: the prototype-first
promoted Oracle normally briefs/navigates rather than continuing as
producer; the contribution recipe allows a bounded
Owner-authorized Oracle edit before handoff. This is not an
automatic permanent permission, and affected claims remain
SELF-ASSESSED until separately required review.

**BuddyRunner/activity suggestion** is an **Owner-selected duty**,
not an automatic requirement in every Oracle session. The source
threshold is strictly `>5` distinct observed GitHub-access turns
**OR** `>35` recorded active-turn minutes in one relevant
ChatGPT-agent episode. ChatGPT Work and explicit exemptions
follow the selected source profile; do not invent counters,
assume all clients are eligible, infer elapsed reasoning time,
or automatically terminate work.

**No mandatory Gatekeeper module** for every product. If the Owner
selects Gatekeeper or release rules independently require it,
preserve that native byte/coverage and Owner-release authority.
A GitHub Cycle receipt is not a Gatekeeper seal, verified artifact
or release command.

**Progress Page legacy no-Drive-links** at the pinned normative
tree is a public safety policy; the Owner later authorized a narrow
folder-link override in
[separate Progress PR #8](https://github.com/reallakshman19/progress-page/pull/8).
Do not assume that draft policy is merged. No private child file
URLs are placed in public data regardless.

## Provenance / limits

Source-derived requirements above are paraphrases of
the linked file families; the suggested `oracle-standalone`
entrypoint and its GitHub Cycle composition are **new integration
decisions**, not present as an installed skill at the pinned
commit. The current implementation is **documentation + future
host guidance**. It does not prove native cross-chat execution,
GitHub receipt posting, Drive bytes retrieval, authoritative
CAS publication or Progress Page synchronization.

### Fresh-version safety

Use the exact pinned tree when explaining why a rule was
adopted; fetch the **current published** project state and
selected module instructions when executing work. If a newer
instruction materially disagrees, report the discrepancy,
authority and affected scope; never silently merge incompatible
rules or call an older doc current.
